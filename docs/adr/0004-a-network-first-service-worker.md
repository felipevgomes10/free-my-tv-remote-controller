# A network-first service worker keeps the page openable when the TV isn't

The page is served by the Home, so without help, opening FMTV Controller from the Home Screen while the TV is off or the Home is restarting shows Safari's own error page, and the Sem conexão screen and "Tentar ligar a TV" could never appear when they matter. So the page installs a service worker that keeps a copy of the page and always tries the network first: when the Home answers, the newest page loads; when it doesn't, the saved copy opens, says Sem conexão and reconnects by itself. This reverses the spec's first "no service worker" decision, which was meant to stop a Home update leaving an old page cached. The network-first order and the protocol version in the hello, where the bridge tells an outdated page to reload once, cover that risk instead.
